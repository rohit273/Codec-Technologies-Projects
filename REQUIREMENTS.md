# Requirements

## Functional
FR-01 JSON/JSONL/CSV ingestion. FR-02 configurable watchlists. FR-03 case-insensitive matching.
FR-04 basic URL/domain/IPv4 extraction. FR-05 credential-like redaction. FR-06 explainable priority.
FR-07 SHA-256 fingerprint and duplicate suppression. FR-08 JSON/CSV reports.

## Non-functional
Python 3.10+; standard library; no external network in default mode; synthetic demo data; clear input errors.

## Out of scope
Marketplace crawling, Tor automation, credential verification, external API calls, semantic NLP/ML, proof of compromise.
